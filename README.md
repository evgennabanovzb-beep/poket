# Demo Options Studio

Локальный образовательный симулятор терминала бинарных опционов для записи честных обучающих роликов.

## Что важно

- это **не Pocket Option** и не копия реального сайта;
- приложение не подключается к брокерам, API, аккаунтам или торговым серверам;
- свечи, баланс, выплаты и история сделок генерируются локально;
- на экране постоянно есть маркировка `DEMO / СИМУЛЯЦИЯ`, чтобы зрители понимали, что это учебная среда.

## Возможности

- терминальный layout в стиле платформ бинарных опционов: верхняя панель, список активов, центральный свечной график, правая панель сделки и нижняя история;
- кнопки `ВВЕРХ` и `ВНИЗ`, которые запускают управляемую анимацию последней свечи;
- фейковый баланс, прибыль за сессию, счётчик сделок и всплывающий маркер `DEMO WIN`;
- выбор суммы сделки и длительности анимации.

## Запуск

Откройте `index.html` в браузере или запустите локальный статический сервер:

```bash
python3 -m http.server 4173
```

Затем перейдите на `http://localhost:4173`.
