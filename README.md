# Учебный демо-терминал

Это локальный образовательный симулятор свечного графика. Он не копирует интерфейс Pocket Option, не подключается к брокерам и не выполняет реальные сделки.

## Возможности

- локально сгенерированный свечной график;
- кнопки `ВВЕРХ` и `ВНИЗ`, которые запускают управляемую анимацию последней свечи;
- фейковый баланс и журнал демо-сделок;
- постоянная маркировка `DEMO / НЕ РЕАЛЬНЫЕ ТОРГИ`, чтобы зрители понимали, что это симуляция.

## Запуск

Откройте `index.html` в браузере или запустите локальный статический сервер:

```bash
python3 -m http.server 4173
```

Затем перейдите на `http://localhost:4173`.
